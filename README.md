## 月流量用超了怎么收费

入门款 2核2G3M 给 200GB，折合每天 6.6GB。个人博客、企业官网这类以文字和小图为主的站点基本用不完；图床、下载站、视频站就难说了，一个 1GB 的安装包被下载 200 次，当月流量包就见底了。超量后系统自动扣费，也买不到单独的流量包，官方文档写明流量包只能随套餐走。

## 关于价格的几个常见问题

**38 元的轻量服务器是真的吗？**

真的，但它是秒杀价，针对新用户首单、限时限量，常规活动价是 68 元一年（2核2G3M）。抢不到秒杀，按 68 元买也不算亏。

**可以按月买吗？**

可以，包年包月最短 1 个月。4核16G14M 是 99 元一个月、297 元三个月、1584 元一年；16核64G35M 是 580 元一个月、1740 元三个月、6960 元一年。短期项目按月买更灵活。

**香港节点贵多少？**

主要贵在流量，香港地域超额流量约 1 元/GB，大陆约 0.8 元/GB。套餐本身的价格也会略高，具体看活动页。

**续费会涨价吗？**

看套餐。标注“同价续费”“续费不涨价”的不涨；没标注的按当期官网价续费，官网价通常高于活动价。买之前确认续费价，或者直接买 3 年锁定成本。

**买小了能升级吗？**

只能整体升级到更高档套餐，不能降级，也不能单独加内存或带宽。所以宁可从低一档开始，确认不够再整体升。
